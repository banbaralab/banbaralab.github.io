ようこそ

番原・宋研究室は，知識表現および推論 （Knowledge Representation and Reasoning; KRR） の分野において，基礎理論から社会実装まで幅広く研究を行っています． 特に，宣言的問題解決（Declarative Problem Solving）のための汎用的アプローチに注目し， 解集合プログラミング（Answer Set Programming; ASP）， 充足可能性判定（Satisfiability Testing; SAT）， 制約プログラミング（Constraint Programming; CP）を中心に研究を進めています．

高校生と学部生の方は，名古屋大学情報学部のブログに書いた記事 「SAT紹介 (高校生対象)」 と 「看護師の勤務表作成 〜解集合プログラミングの応用〜（高校生・学部生対象）」 をご覧ください．

パズル好きの方には Nagoya University Polyomino World (名古屋大学ポリオミノの世界) がお薦めです．
